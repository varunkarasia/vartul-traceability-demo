# Vartul traceability demo

An interactive waste-to-product journey: mixed incoming packaging, sorted film bales, recycling, granules and recycled industrial film.

The sample scan traces the product backwards to its origin, then opens an explorable network of material, process, participant-role and evidence connections. Includes replay, pause, skip, keyboard navigation and a linear alternative.

## Demo only

All batch data, participant roles and records are illustrative. The scan is simulated: no camera, live lookup, upload or backend is used. Missing evidence is not verified by scanning. Photographs illustrate the process and are not records of actual production events.

## Hosting

Static HTML, CSS, JavaScript and images. GitHub Pages serves the root of `main`; `.nojekyll` disables Jekyll processing. Relative asset paths support a project-site URL. No build step, secrets or authentication are required. Google Fonts is optional; the page falls back to local fonts.

Search indexing remains disabled for this demonstration.
