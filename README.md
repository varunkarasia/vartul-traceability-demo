# Vartul traceability demo

An interactive waste-to-product journey: mixed incoming packaging, sorted film bales, recycling, granules and recycled industrial film.

The sample scan traces the product backwards to its origin, then opens an explorable network of material, process, participant-role and evidence connections. Includes replay, pause, skip, keyboard navigation and a linear alternative.

The services section introduces Traceability, IoT and Chain Verification. Three illustrative device capture points connect input weight, a machine process event and output batch identification to their sample network records. Device capture does not verify the chain.

## Demo only

All batch data, participant roles and records are illustrative. The scan is simulated: no camera, live lookup, upload or backend is used. Missing evidence is not verified by scanning. Photographs illustrate the process and are not records of actual production events.

## Hosting

Static HTML, CSS, JavaScript and images. GitHub Pages serves the root of `main`; `.nojekyll` disables Jekyll processing. Relative asset paths support a project-site URL. No build step, secrets or authentication are required. Google Fonts is optional; the page falls back to local fonts.

Search indexing remains disabled for this demonstration.


## Windows & glass companion

The `fenestration/` page follows an illustrative aluminium-framed, single-glazed window. Separate profile and glass lots become frame and pane components, converge with fittings at assembly, and continue through inspection to dispatch and an open installation handoff. A reverse scan reveals both origins. Machine-event, component-identifier and inspection captures are demonstrations only. No device protocol, live production connection, certification or performance result is claimed.

Five generated photographic illustrations show incoming materials, guarded profile cutting, glass processing, assembly identification and a finished window. They are not production evidence.

Manufacturing context was checked against [Reynaers fabrication process descriptions](https://www.reynaers.com/resource/41815/download) and [Pilkington glass processing information](https://www.pilkington.com/en-us/united-states-and-canada/knowledge-hub-selection/architectural-and-technical-glass-knowledge-hub/learn-about-glass-technology/glass-processing). The fictional lots and records do not represent those companies or their products.
